**Мониторинг компьютеров локальной сети: клиент-агент и сервер сбора данных**

Агент устанавливается на компьютеры сотрудников и по таймеру отправляет на сервер администратора сведения о машине. Администратор видит все компьютеры сети в одной таблице.

## Что собирает агент

- имя компьютера и пользователя;
- IP-адреса;
- логические диски: тип, файловая система, метка, объём и свободное место;
- запущенные процессы и занимаемую ими память.

## Возможности

- **Клиент** (`LANAgentClient`): работает в системном трее, отправляет данные по TCP, настройки (адрес и порт сервера) хранит в реестре, умеет добавлять себя в автозагрузку.
- **Сервер** (`LanAgentServer`): асинхронно принимает подключения (`TcpListener`), выводит список клиентов, по двойному щелчку показывает подробности (процессы, диски). Список можно сохранить в файл и загрузить.
- **Общая библиотека** (`DLLLanAgent`): сериализуемый класс `ClientInfo`, которым обмениваются клиент и сервер.
- Файл справки (`HTML Help/help.chm`) и проекты установщиков (`Instal/`).

## Структура

```
├── LANAgentClient (корень)    агент для рабочих станций
├── 2024_02-11LanAgentServer/  сервер администратора
├── DLLLanAgent/               общая библиотека ClientInfo
├── HTML Help/                 справка
└── Instal/                    проекты установщиков
```

## Как запустить

1. Откройте и соберите `DLLLanAgent/DLLLanAgent.sln`, затем сервер и клиент (Visual Studio 2022).
2. Запустите сервер, укажите адрес и порт (по умолчанию 5000), нажмите «Старт».
3. На этом же или другом компьютере запустите клиент и укажите адрес сервера.
